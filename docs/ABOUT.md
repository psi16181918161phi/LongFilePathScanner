# About

Long File Path Scanner is a tool designed to help developers find files with excessively long paths. This project aims to improve filesystem compatibility and performance by identifying potential issues in project directories.

## Features

- **Recursive Scanning:** Search directories and subdirectories.
- **Length Analysis:** Identify files that exceed typical path length limits.
- **Reporting:** Generate detailed reports to facilitate fixes.
- **Cross-Platform:** Works on various operating systems.

## Usage

Simply run the scanner on your directory:
```bash
longfilepathscanner /path/to/your/project
```
Review the output report to identify and resolve issues with long file paths.
