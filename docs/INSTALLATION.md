# Installation

Follow these instructions to install and run LongFilePathScanner.

## Requirements

- Windows operating system
- [.NET SDK](https://dotnet.microsoft.com/download) (version 5.0 or later)
- Git

## Installation Steps

1. **Clone the Repository**  
    Open a terminal and run:
    ```bash
    git clone https://github.com/yourusername/LongFilePathScanner.git
    ```

2. **Navigate to the Project Directory**  
    ```bash
    cd LongFilePathScanner
    ```

3. **Build the Project**  
    ```bash
    dotnet build
    ```

4. **Run the Scanner**  
    ```bash
    dotnet run
    ```

## Usage

Upon running, follow the on-screen instructions to scan directories and detect long file paths. For more detailed usage instructions, refer to the [Usage Guide](USAGE.md).

## Troubleshooting

If you encounter issues during installation or execution, consider the following:
- Verify that the .NET SDK is properly installed.
- Check that your environment variables are set correctly.
- Consult the [Troubleshooting Guide](TROUBLESHOOT.md) for common issues.

Enjoy using LongFilePathScanner!
